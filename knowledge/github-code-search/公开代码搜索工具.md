# 公开代码搜索（grep.app 类工具）

## 能干什么

在**公开的** GitHub 代码里按字面量/正则检索真实用法：语料是别人的仓库，适合查"某 API 到底怎么调""某报错别人怎么解决""某库有没有人这么写"。

> 草图：[`公开代码搜索的边界.excalidraw`](./公开代码搜索的边界.excalidraw)（OpenChamber 的 Files 视图里点开就是画布）

只读公开代码，不需要登录：你的查询 → grep.app 索引 → 命中仓库 / 路径 / 片段 / 许可证。

典型用途：找 CLI 的真实用法、找配置写法、验证"这个参数是不是真存在"、抄之前先看别人的实现和许可证。

## 不能干什么

- ❌ 搜自己的**私有**仓库、自己的本地代码 —— 它只索引公开代码。
- ❌ 当成 GitHub 账号操作工具 —— 它没有你的凭据，不碰 issue / PR / 分支。
- ⚠️ 抄代码要看 **License 字段**，有的片段来自许可证不明的仓库。

## 环境里常见形态

同一个服务常被配成 **remote MCP**，定义极简、**不需要 API key**：

```json
{ "type": "remote", "url": "https://mcp.grep.app", "oauth": false }
```

于是可能出现"配了两遍"：你自己在全局配置里配一次，某个插件又内置一份（名字不同、URL 相同），
两边都能用、结果一样 —— 排查"为什么有两个搜索工具"时，先比对 URL 再判断是不是重复。

## 和 `gh` CLI 的分工

| 需求 | 用哪个 |
|---|---|
| 查公开代码怎么写 | 公开代码搜索（grep.app 类） |
| 查自己的仓库、私有仓库、issue/PR | `gh` CLI（带凭据） |
| 查库的官方文档 | 文档型 MCP（如 context7 类），不是代码搜索 |

一句话：**没有凭据的检索工具只能看公开世界**；要碰自己的东西就得用带认证的 CLI。
