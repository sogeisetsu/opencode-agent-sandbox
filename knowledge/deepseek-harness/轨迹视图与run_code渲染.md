# DSH 轨迹视图与 `run_code` 渲染

> 核对：2026-11-12。依据：2026-11-09～11-11 的会话实测（轨迹面板操作、PTC 预设演示）与源码/预设阅读；本轮未重跑。DSH 为 nightly 预发布，UI 结构会漂移。

## 一句话

轨迹（Trajectory）是**把原始事件流水摊平**，不是聊天记录；`run_code` 是 **PTC（programmatic tool calling）执行器的工具名，不是 UI 按钮**——它只在会话选了 `ptc` 预设、且模型真的调用过一次之后才会出现。

## 轨迹的三条泳道

每条用户消息、每次模型请求、每个工具调用（含 `run_code` 里的嵌套子调用）都占一行，按「第 N 轮」→「第 N 步」分组；**只读**，不改会话。

| 泳道 | 装什么 | 颜色 |
|---|---|---|
| 输入 | 系统、用户、上下文、压缩记录 | 蓝=用户，绿=上下文，灰=系统/压缩 |
| 模型 | 助手消息（每次模型请求的产出） | 紫 |
| 工具 | `tool` / `subtool` | 橙=工具，浅橙=子工具，红=失败 |

## 两种排列方式（最容易误解）

- 默认方块等宽等距 = **按发生顺序**，与真实耗时无关。
- 点「时长」后宽度按**真实记录时长**成比例，空闲间隔被压缩；**点击不重新计时**，只是换布局。
- 悬停提示会说明点击后切换到哪种布局。

## 四个按钮

| 按钮 | 作用 |
|---|---|
| **时长**（时钟图标） | 在「等宽顺序」与「实际时长」之间切换彩带布局；不重新计时；悬停提示说明点击后切到哪种 |
| **轮次** | 一键收起/展开所有轮次（⊟ / ⊞），收起后每轮压成一行摘要 |
| **调用** | 一键收起/展开所有助手调用（每条模型请求的助手输出行） |
| **子调用** | 一键收起/展开工具下的嵌套子调用；收起后父工具下留一条摘要，点摘要或按 Enter/空格展开 |

## 交互

- 彩带上**水平拖选** → 表格只保留该时段有活动的行。
- **滚轮**缩放时间轴。
- **右键**清除选区、右键拖动平移。
- 悬停 **500ms** 显示精确开始时刻、总时长、TTFT/解码拆分。
- 搜索框支持搜已折叠的子调用并自动展开。

## 表格怎么读

- 行首类型标签：系统 / 用户 / 上下文 / 消息 / 助手 / 工具 / 子工具 / 已压缩。
- 行左侧**小圆点**是「请求 #N」边界：点它选中该请求全部记录，并让右侧检查器切到该请求。
- 行尾 `→` 后是结果预览，`...` 表示截断。
- 点任意行打开检查器，页签包括：概述、原始输出、预览、原始内容、来源、参数、结果、Schema、计时、差异、系统提示词、工具、选项、用量。

三种实用套路：

| 想知道 | 操作 |
|---|---|
| 慢在哪 | 开「时长」看哪段橙块最宽、空闲间隙在哪、有没有红块 |
| 模型到底看到了什么 | 点请求圆点看系统提示词/工具目录/参数 |
| 只看骨架 | 用三个折叠按钮（轮次/调用/子调用）压掉细节 |

## `run_code` 与 PTC 模式

- **`run_code` 是工具名，不是按钮。** 它是 **PTC** 的执行器：让模型写一段 TypeScript/Python 程序，在程序里连续 `await tools.pwsh(...)`、`await tools.read(...)`，由 Node 运行时执行。
- 特殊渲染只对工具名为 `run_code` 的记录出现：表格行内显示那段程序的**说明文字**；点开检查器才有「代码」页签——带行号、语法高亮的源码、换行开关、**`{}` 按钮**（源码 ↔ 原始 JSON 参数）、保留末尾换行的复制。普通工具（如 `pwsh`）走通用渲染，只有参数/结果 JSON。
- 为什么「看不到」：如果该会话全程只用 `pwsh`/`grep`/`read`/`write`/`edit`，**一次 `run_code` 调用都没发生**，不是功能缺失。
- 启用链路：`run_code` 由 `@deepseek-ai/dsh-tool-executor-ptc` 提供；`dsh-base` 装配里该执行器是 `disabled: true`；应用自带预设 `dsh-web-app/presets/ptc.patch.yml` 把它打开。
- 正确用法：**新建会话时选 `ptc` 预设**（按会话生效，其他会话不受影响）。ptc 下工具面整体替换：不再是「一工具一 schema」，而是「一段生成的 TypeScript SDK 说明 + 唯一一个 `run_code`」；其他工具必须在程序里 `await tools.xxx(...)`。

演示步骤：新建 ptc 会话 → 给任务「用 run_code 列出当前目录文件，再读 `package.json` 前 10 行」→ 打开该会话轨迹 → 工具泳道出现橙色 `run_code` 记录 → 点击看「代码」页签；其下挂浅橙色子调用（程序里每个 `tools.xxx()` 一条），顶部「子调用」按钮可折叠。
