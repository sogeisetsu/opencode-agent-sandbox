# 跑分口径：同名基准不同 harness 不可直接相减

## 一句话

同一个基准名在不同运行方、版本、推理档下能差十几分；厂商自测与独立实验室要分开看，跨来源只能看趋势，不能当精确排名。

## 差异实例（文档级，2026-11 快照）

- Terminal-Bench 4.0：DeepSeek V4.1 Flash 在腾讯口径 40.0、在 MiniMax 发布表 42.3、在 Vals AI 39.39、在 Artificial Analysis 26.8；GLM-5.3 Flash 腾讯 35.4、AA 32.8。
- AA Intelligence Index：版本差异很大——GLM-5.3 在 v5.0.1 的 max 档是 32，旧口径引用为 42；GLM-5.3 Flash 是 28 对 42；MiniMax M3.1 Flash 是 29 对 42、DeepSeek 1017 是 33 对 45。
- Vals Index 也有版本差：Hy4 当前页 57.87%，v2.2 口径 59.35%。
- DeepSWE：GLM-5.3 Flash 自家 63.4、腾讯 67.8。
- 厂商自建集（腾讯金融众测 3.04/4、Plotly 私有数据分析集 39/43）只说明该场景，不能推广成通用排名。

## 读分的四条判据

1. 谁跑的（runner / harness 名字）。
2. 基准版本（Terminal-Bench 2.1 / 4.0，Index v4.x / v5.0.1）。
3. 推理档位（max / low / 非思考）以及样本数与置信区间。
4. 只在同来源内部相减，跨来源只排量级。

## 验证方法

本次会话用只读抓取复核了 Vals AI 的两个模型页与 Artificial Analysis 的 GLM 对比页：Hy4 Flash 的 Vals Index 为 49.16% ±1.11（36/43），GLM-5.3 与 GLM-5.3-Flash 在 AA v5.0.1 上分别为 32 与 28。这两个数直接支撑上面的「版本 / 来源差异」结论。

## 已验证 / 文档级 / 未验证

- **文档级**：上述分数来自第三方实验室与厂商公开页面，本次没有本地复跑。
- **未验证**：各分数的采样温度、缓存设置与失败重试策略；不同来源排名不一致时谁更接近真实生产表现。

时效性：模型与榜单迭代快，这是 2026-11 快照，两个月后需重新核对。
